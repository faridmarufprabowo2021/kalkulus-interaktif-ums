Week 2: Trigonometri & Lingkaran Satuan

Dari segitiga siku-siku Pythagoras hingga lingkaran satuan $r=1$: perputaran sudut dinamis, kaidah kuadran ASTC, 8 keluarga identitas trigonometri, dan penyelesaian analitis persamaan transenden.

"Pada lingkaran satuan $x^2 + y^2 = 1$, koordinat titik ujung jari-jari sudut $\theta$ mendefinisikan secara langsung $x = \cos \theta$ dan $y = \sin \theta$. Identitas Pythagoras $\sin^2\theta + \cos^2\theta = 1$ tak lain adalah manifestasi jarak Euclidean."

1. Geometri Segitiga & Lingkaran Satuan

Pondasi mendasar rasio sudut, konversi derajat-radian, serta kaidah tanda 4 kuadran.

Segitiga Siku-Siku (Rasio Dasar)

Untuk sudut lancip $\theta$ dengan sisi depan $y$, samping $x$, dan sisi miring $r = \sqrt{x^2+y^2}$:
$$\sin\theta = \frac{y}{r}, \quad \cos\theta = \frac{x}{r}, \quad \tan\theta = \frac{y}{x}$$ $$\csc\theta = \frac{1}{\sin\theta}, \quad \sec\theta = \frac{1}{\cos\theta}, \quad \cot\theta = \frac{1}{\tan\theta}$$

Konversi Derajat & Radian

Satu putaran penuh = $360^\circ = 2\pi\text{ rad}$. Maka:
$$180^\circ = \pi\text{ rad} \implies 1^\circ = \frac{\pi}{180}\text{ rad}, \quad 1\text{ rad} = \frac{180^\circ}{\pi} \approx 57.2958^\circ$$ Panjang busur lingkaran: $s = r\theta$ (dengan $\theta$ dalam radian). Luas juring lingkaran: $L = \frac{1}{2}r^2\theta$.

8 Kelompok Identitas Utama Trigonometri

1. Pythagoras

$\sin^2\theta + \cos^2\theta = 1$
$1 + \tan^2\theta = \sec^2\theta$
$1 + \cot^2\theta = \csc^2\theta$

2. Ganjil-Genap

$\sin(-\theta) = -\sin\theta$
$\cos(-\theta) = \cos\theta$
$\tan(-\theta) = -\tan\theta$

3. Sudut Berelasi / Komplemen

$\sin(90^\circ - \theta) = \cos\theta$
$\cos(90^\circ - \theta) = \sin\theta$
$\tan(90^\circ - \theta) = \cot\theta$

4. Sudut Ganda

$\sin 2\theta = 2\sin\theta\cos\theta$
$\cos 2\theta = \cos^2\theta - \sin^2\theta$
$\phantom{\cos 2\theta} = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$

5. Jumlah & Selisih

$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$
$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$

6. Setengah Sudut

$\sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}}$
$\cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}}$
$\tan\frac{\theta}{2} = \frac{1-\cos\theta}{\sin\theta}$

7. Sum-to-Product

$\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$
$\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$

8. Product-to-Sum

$2\sin A\cos B = \sin(A+B) + \sin(A-B)$
$2\cos A\cos B = \cos(A+B) + \cos(A-B)$

Latihan Soal Uji Kompetensi (Medium to High)

10 soal terkalibrasi menguji identitas sudut ganda, analisis kuadran ASTC, dan penyelesaian analitis persamaan trigonometri.

Skor Anda: 0 / 10
SOAL 01 Medium
Jika diketahui $\cos \theta = -\frac{5}{13}$ dan sudut $\theta$ terletak di Kuadran III, maka nilai dari $\tan \theta + \csc \theta$ adalah...
Langkah Pembuktian:
Di Kuadran III: nilai $x < 0$ dan $y < 0$.
Diketahui $\cos\theta = \frac{x}{r} = -\frac{5}{13} \implies x = -5, r = 13$.
$y = -\sqrt{r^2 - x^2} = -\sqrt{13^2 - (-5)^2} = -\sqrt{169 - 25} = -\sqrt{144} = -12$.
Maka:
$\tan\theta = \frac{y}{x} = \frac{-12}{-5} = \frac{12}{5}$.
$\sin\theta = \frac{y}{r} = -\frac{12}{13} \implies \csc\theta = \frac{1}{\sin\theta} = -\frac{13}{12}$.
Hasil penjumlahan: $$\tan\theta + \csc\theta = \frac{12}{5} - \frac{13}{12} = \frac{144 - 65}{60} = \frac{79}{60}.$$
SOAL 02 Medium
Nilai eksak dari $\sin 105^\circ$ dapat dihitung menggunakan rumus jumlah dua sudut istimewa $\sin(60^\circ + 45^\circ)$. Nilai eksak tersebut adalah...
Rumus Jumlah Sudut Sinus:
$$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$ Substitusi $\alpha = 60^\circ$ dan $\beta = 45^\circ$: $$\sin(60^\circ + 45^\circ) = \left(\frac{\sqrt{3}}{2}\right)\left(\frac{\sqrt{2}}{2}\right) + \left(\frac{1}{2}\right)\left(\frac{\sqrt{2}}{2}\right) = \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4} = \frac{\sqrt{6} + \sqrt{2}}{4}.$$
SOAL 03 Medium
Himpunan penyelesaian dari persamaan kuadrat trigonometri $2\sin^2 x - 3\sin x + 1 = 0$ untuk interval $0 \le x \le 2\pi$ adalah...
Faktorisasi Aljabar:
Faktorkan persamaan kuadrat dalam variabel $\sin x$:
$$(2\sin x - 1)(\sin x - 1) = 0$$ Diperoleh 2 cabang solusi:
1) $2\sin x - 1 = 0 \implies \sin x = \frac{1}{2} \implies x = \frac{\pi}{6}$ atau $x = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$.
2) $\sin x - 1 = 0 \implies \sin x = 1 \implies x = \frac{\pi}{2}$.
Gabungan solusi pada $[0, 2\pi]$: $\left\{\frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}\right\}$.
SOAL 04 Medium
Bentuk pecahan trigonometri $\frac{\sin 2x}{1 + \cos 2x}$ dapat disederhanakan secara aljabar menjadi bentuk tunggal...
Substitusi Identitas Sudut Ganda:
Ingat bahwa $\sin 2x = 2\sin x \cos x$ dan $\cos 2x = 2\cos^2 x - 1$.
Maka penyebut: $1 + \cos 2x = 1 + (2\cos^2 x - 1) = 2\cos^2 x$.
Pecahan menjadi: $$\frac{2\sin x \cos x}{2\cos^2 x} = \frac{\sin x}{\cos x} = \tan x.$$
SOAL 05 Medium
Sebuah roda dengan jari-jari $r = 10\text{ cm}$ berputar sejauh sudut pusat $\theta = \frac{7\pi}{6}\text{ radian}$. Berapakah panjang lintasan busur $s$ dan besar sudut dalam satuan derajat?
Perhitungan Busur & Konversi:
1) Panjang busur: $s = r \cdot \theta = 10 \times \frac{7\pi}{6} = \frac{70\pi}{6} = \frac{35\pi}{3}\text{ cm}$.
2) Konversi ke derajat: $\theta = \frac{7\pi}{6} \times \frac{180^\circ}{\pi} = 7 \times 30^\circ = 210^\circ$.
SOAL 06 High
Sederhanakan bentuk selisih sudut berikut menggunakan identitas Sum-to-Product: $$\frac{\sin 7x - \sin 5x}{\cos 7x + \cos 5x}$$
Identitas Sum-to-Product:
Pembilang: $\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2} = 2\cos\left(\frac{7x+5x}{2}\right)\sin\left(\frac{7x-5x}{2}\right) = 2\cos 6x \sin x$.
Penyebut: $\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2} = 2\cos\left(\frac{7x+5x}{2}\right)\cos\left(\frac{7x-5x}{2}\right) = 2\cos 6x \cos x$.
Hasil bagi: $$\frac{2\cos 6x \sin x}{2\cos 6x \cos x} = \frac{\sin x}{\cos x} = \tan x.$$
SOAL 07 High
Tentukan nilai eksak dari perkalian tiga nilai cosinus berikut: $$\cos 20^\circ \cdot \cos 40^\circ \cdot \cos 80^\circ$$
Trik Teleskopik Sudut Ganda: Kalikan dan bagi dengan $2\sin 20^\circ$:
$$\frac{2\sin 20^\circ \cos 20^\circ \cos 40^\circ \cos 80^\circ}{2\sin 20^\circ} = \frac{\sin 40^\circ \cos 40^\circ \cos 80^\circ}{2\sin 20^\circ}$$ Kalikan pembilang dan penyebut dengan 2: $$= \frac{2\sin 40^\circ \cos 40^\circ \cos 80^\circ}{4\sin 20^\circ} = \frac{\sin 80^\circ \cos 80^\circ}{4\sin 20^\circ}$$ Kalikan lagi dengan 2: $$= \frac{2\sin 80^\circ \cos 80^\circ}{8\sin 20^\circ} = \frac{\sin 160^\circ}{8\sin 20^\circ}$$ Karena $\sin 160^\circ = \sin(180^\circ - 20^\circ) = \sin 20^\circ$, maka: $$\frac{\sin 20^\circ}{8\sin 20^\circ} = \frac{1}{8}.$$
SOAL 08 High
Tentukan nilai minimum dan nilai maksimum dari fungsi trigonometri linear kombinasi: $$f(x) = 3\sin x - 4\cos x + 5$$
Bentuk $A\sin x + B\cos x = R\sin(x + \alpha)$:
Amplitudo gelombang resultan $R = \sqrt{A^2 + B^2} = \sqrt{3^2 + (-4)^2} = \sqrt{9 + 16} = 5$.
Karena rentang nilai sinus adalah $[-1, 1]$, maka $-5 \le 3\sin x - 4\cos x \le 5$.
Tambahkan konstanta 5 ke seluruh rentang:
$-5 + 5 \le f(x) \le 5 + 5 \implies 0 \le f(x) \le 10$.
Jadi Nilai Minimum $= 0$ dan Nilai Maksimum $= 10$.
SOAL 09 High
Berapa banyak solusi $x \in [0, 2\pi)$ yang memenuhi persamaan trigonometri: $$\cos 3x = \cos 2x$$
Analisis Solusi Umum Cosinus:
$\cos 3x = \cos 2x \iff 3x = 2x + 2k\pi$ atau $3x = -2x + 2k\pi$.
1) $3x - 2x = 2k\pi \implies x = 2k\pi$.
Untuk rentang $[0, 2\pi)$, diperoleh $x = 0$ (karena $2\pi$ tidak termasuk interval terbuka kanan).
2) $3x + 2x = 2k\pi \implies 5x = 2k\pi \implies x = \frac{2k\pi}{5}$.
Untuk $k = 0, 1, 2, 3, 4$:
$x = 0, \frac{2\pi}{5}, \frac{4\pi}{5}, \frac{6\pi}{5}, \frac{8\pi}{5}$.
Semua 5 nilai ini berada dalam rentang $[0, 2\pi)$. Jadi terdapat tepat 5 solusi unik.
SOAL 10 High
Nilai eksak dari $\tan 22.5^\circ$ (atau $\tan \frac{\pi}{8}$) yang diturunkan melalui identitas setengah sudut $\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta}$ adalah...
Identitas Setengah Sudut Tangen:
Pilih $\theta = 45^\circ$, sehingga $\theta/2 = 22.5^\circ$.
$$\tan 22.5^\circ = \frac{1 - \cos 45^\circ}{\sin 45^\circ} = \frac{1 - \frac{\sqrt{2}}{2}}{\frac{\sqrt{2}}{2}} = \frac{2 - \sqrt{2}}{\sqrt{2}} = \frac{2}{\sqrt{2}} - 1 = \sqrt{2} - 1.$$
